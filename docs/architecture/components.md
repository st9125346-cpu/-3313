Frontend:
  Призначення: Інтерфейс для взаємодії користувача із системою
  Основні функції:
    - Авторизація / реєстрація
    - Створення, редагування, видалення задач
    - Зміна статусу задач
    - Відображення списків / Kanban-дошки
  Інтерфейс / Протокол: HTTP/HTTPS → REST API
  Дані:
    Вхід: JSON-відповіді API
    Вихід: GET/POST/PUT/DELETE запити
  Технології: React / Vue / Angular

Backend:
  Призначення: Обробка бізнес-логіки та взаємодія з базою даних
  Основні функції:
    - CRUD операції з задачами
    - Авторизація (токени)
    - Валідація даних
    - Управління користувачами
  Інтерфейс / Протокол: REST API (JSON)
  Дані:
    Вхід: HTTP-запити
    Вихід: JSON-відповіді
  Технології: Node.js / NestJS / Django / Spring

API:
  Призначення: Точка входу для клієнтських запитів
  Основні функції:
    - Маршрути /tasks, /users, /auth
    - Обробка запитів
    - Формування JSON-відповідей
  Інтерфейс / Протокол: HTTP REST
  Дані: JSON (вхід/вихід)
  Технології: Express / NestJS / Fastify

Database:
  Призначення: Зберігання даних задач та користувачів
  Основні функції:
    - Таблиця задач (назва, опис, дедлайн, статус)
    - Таблиця користувачів
    - Пошук та фільтрація
  Інтерфейс / Протокол: SQL-клієнт або ORM
  Дані: записи задач та користувачів
  Технології: PostgreSQL / MySQL / MongoDB

ExternalServices:
  Призначення: Додаткові інтеграції
  Основні функції:
    - Email-сповіщення
  Інтерфейс / Протокол: SMTP / API
  Дані: листи
  Технології: Mailgun / Gmail API

ObservabilityInfra:
  Призначення: забезпечення стабільності, логування і розгортання
  Основні функції:
    - Логи
    - CI/CD
    - Моніторинг
  Інтерфейс / Протокол: Docker, GitHub Actions
  Дані: лог-файли
  Технології: Docker, GitHub Actions, Logger
